## Description

This project is a responsive e-commerce website for Furnipol, a furniture company. It showcases various furniture collections, categories, and promotions with a modern design optimized for both desktop and mobile devices.

## Features

- **Responsive Design**: Optimized for desktop, tablet, and mobile devices
- **Hero Slider**: Dynamic image carousel on the homepage
- **Product Categories**: Browse furniture by rooms and categories
- **Collection Tabs**: Explore different furniture collections
- **Favourite Categories**: Highlighted popular product categories
- **Sale Section**: Promotional offers and discounts
- **Newsletter Signup**: Email subscription for updates
- **Customer Reviews**: Trustpilot integration for reviews
- **Cart Preview**: Quick view of shopping cart items
- **Mobile Menu**: Touch-friendly navigation for mobile users
- **Tapbar**: Additional navigation bar for mobile

## Technologies

Used technologies:

- JavaScript
- jQuery 1.12.2

- Bootstrap 3.3.7
- HTML5
- SCSS

## Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/goldipl/furnipol-furnitures.git
   ```

2. Navigate to the project directory:

   ```bash
   cd furnipol-furnitures
   ```

3. Open `index.html` in your web browser to view the website.

**Note**: The styles are written in SCSS. To modify styles, edit the files in the `sass/` directory and compile them to CSS. The compiled CSS files are already included in the `css/` directory.
